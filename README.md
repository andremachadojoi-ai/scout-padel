# Scout Padel — V2 (GitHub Pages)

Aplicativo web progressivo (PWA) para registrar scouts de partidas de padel.

## Recursos
- Cadastro de partida, duplas e quatro atletas
- Marcação rápida: atleta e golpe permanecem selecionados entre os registros
- Resultados: erro não forçado, erro forçado, winner e acerto
- Seleção de set e registro opcional do placar de cada set
- Estatísticas por set e por atleta
- Comparativo entre duplas
- Observações técnicas e táticas
- Exportação CSV e relatório imprimível/salvável como PDF
- Salvamento local no navegador/aparelho

## Publicação no GitHub Pages
O workflow em `.github/workflows/deploy.yml` publica o conteúdo da raiz quando acionado. Na primeira configuração, abra **Settings → Pages** e selecione **GitHub Actions** em **Build and deployment → Source**. Depois, acompanhe a publicação na aba **Actions**.

## Instalar no iPhone
1. Abra a URL do GitHub Pages no Safari.
2. Toque em Compartilhar.
3. Escolha **Adicionar à Tela de Início**.

## PDF
Abra Relatório → PDF. Na janela de impressão, escolha salvar em Arquivos como PDF.

## Dados e privacidade
Esta versão salva os dados localmente no navegador/aparelho. Não há login, sincronização entre dispositivos ou backup em nuvem. Evite limpar os dados do Safari antes de exportar relatórios importantes.
